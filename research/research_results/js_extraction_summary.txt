================================================================================
DIN-Brief NEO - JavaScript Funktionsübersicht (website/js/)
Stand Repository: origin/main (Commit 1b663fa)
================================================================================

1. DRAFT MANAGEMENT (01-draft-manager.js)
   - constructor(onSaveCallback) : Initialisiert den DraftManager.
   - saveDraft()                 : Speichert aktuellen Entwurf in LocalStorage / History.
   - loadDraft()                 : Lädt gespeicherten Entwurf.
   - undo()                      : Rückgängig-Funktion für Textänderungen.
   - redo()                      : Wiederholen-Funktion.
   - traverseNodes(node)         : Hilfsfunktion zum Durchlaufen von DOM-Knoten für Draft State.
   - resetDraft()                : Setzt den Entwurf auf Standardwerte zurück.
   - scheduleAutoSave()          : Plant automatisches Speichern nach Inaktivität.
   - _updateDocumentTitle()      : Aktualisiert den Browsertitel basierend auf Empfänger/Betreff.

2. SETTINGS & STYLES (02-settings-manager.js)
   - constructor()               : Initialisiert den SettingsManager.
   - init()                      : Lädt und wendet initial Einstellungen an.
   - applySettings()             : Wendet Theme, Font, Hilfslinien etc. an.
   - applyThemeDim(dim)          : Stellt Dunkelstufe / Helligkeit ein.
   - updateSettings()            : Speichert geänderte Einstellungen.
   - initFontInjection()         : Initialisiert benutzerdefinierte Schriftarten.
   - injectFont(base64Font)      : Bindet Base64-Font via CSS @font-face ein.
   - updateFontStatusUI(...)     : Aktualisiert die Schriftarten-Anzeige in den Einstellungen.
   - attachListeners()           : Event-Listener für Einstellungen (Schalter, Regler).
   - handleThemeChange(theme)    : Theme-Wechsel (Hell / Dunkel / Dim).
   - handleGuidesToggle()        : Blendet DIN-Falz- und Lochmarken / Hilfslinien ein/aus.

3. UI-PROTECTIONS & EDITING LIMITS (03-ui-protections.js)
   - constructor()               : Initialisiert UIProtections.
   - init()                      : Registriert Keydown-, Input- und BeforeInput-Guards.
   - enforceLineLimits()         : Verhindert Enter/Zeilenumbrüche in einzeiligen Feldern.
   - protectAnlagenList()        : Schützt die Anlagen-Liste vor Strukturzerstörung.
   - ensureListStructure(...)    : Stellt sicher, dass UL/LI-Strukturen valide bleiben.

4. FORMAT TOOLBAR (31-format-toolbar.js)
   - constructor(...)            : Initialisiert WYSIWYG-Formatierungs-Toolbar.
   - init()                      : Registriert Button-Events (Fett, Kursiv, Unterstrichen etc.).
   - sanitizeNode(node)          : Bereinigt eingefügte HTML-Knoten (Sanitization).
   - toggleFormat(tagName)       : Schaltet Inline-Formatierung im Brieftext um.

5. TOAST NOTIFICATIONS (32-toast.js)
   - constructor()               : Initialisiert ToastSystem mit Gruppierung (state.toast, etc.).
   - initDOM()                   : Erstellt/findet Toast-Container im DOM.
   - onPointerDown / Move / Up   : Swipe-to-Dismiss Geste für Mobilgeräte/Touch.
   - show(...)                   : Zeigt eine Toast-Benachrichtigung an.
   - update(...)                 : Aktualisiert bestehenden Toast.
   - processQueue()              : Arbeitet Toast-Warteschlange ab.
   - startTimer / pause / resume : Steuert Anzeige-Dauer (nutzt performance.now()).
   - clearTimer()                : Bereinigt aktiven setTimeout-Timer.
   - cleanupPopover()            : Räumt Popover-Ressourcen auf.
   - initToastSystem()           : Globale Initialisierungsfunktion.

6. SALUTATION ENGINE (41-salutation-engine.js)
   - normalizeFormality(f)       : Normalisiert Anredeform (formal / informal).
   - splitTitles(name)           : Extrahiert Titel (Dr., Prof., etc.) aus Namen.
   - derive(...)                 : Generiert automatische Anrede (z.B. "Sehr geehrte Frau...").
   - getClosing(formality)       : Erzeugt Grußformel (z.B. "Mit freundlichen Grüßen").
   - getFallback(formality)      : Standard-Fallback-Anrede.
   - init() / _applyUIState()    : Verbindet Engine mit UI-Eingabefeldern.
   - _wireFormality/Gender/etc.  : Registriert Event-Handler für automatische Anrede-Updates.
   - _validatePunctuation(...)   : Stellt Kommasetzung nach Anrede/Grußformel sicher.

7. SIGNATURE OVERLAY (42-signature.js)
   - constructor(uiContext)      : Initialisiert Unterschriften-Overlay.
   - init()                      : Event-Listener für Upload, Drag, Resize, Rotation.
   - initWysiwyg()               : Stellt Drag-&-Drop-Gesten im Briefblatt bereit.
   - applyTransform()            : Wendet CSS-Transform (Verschiebung/Skalierung) an.
   - processFile(file)           : Verarbeitet Bild-Datei.
   - compressImage(bitmap)       : Komprimiert Bild via createImageBitmap.
   - saveAndApply / applyImage   : Speichert und rendert Unterschriftenbild im Dokument.
   - resetImage()                : Entfernt Unterschrift.

8. ADRESSE & GEOAPIFY (43-geoapify.js)
   - initAddressServices(...)    : Initialisiert Geoapify-Autovervollständigung für Adressen.
   - validateKeyWithHeartbeat()  : Validiert API-Key per Testanfrage.
   - getLocalAddressBook()       : Lädt lokales Adressbuch aus Storage.
   - saveToLocalAddressBook()    : Speichert ausgewählte Adresse lokal.
   - fuzzySearchLocal(...)       : Lokale Suche im Adressbuch.
   - performAddressSearch(...)   : Kombinierte Suche (lokal + Geoapify API).
   - renderSuggestions(...)      : Rendert Autocomplete-Vorschlagsliste.
   - selectSuggestion(item)      : Übernimmt gewählte Adresse in Empfängerfeld.

9. ABSENDER-SYNC (44-sender-sync.js)
   - abbreviateName(fullName)    : Kürzt Namen für die Rücksendezeile ab.
   - initSenderSync()            : Verbindet Absender-Formular mit Rücksendezeile.
   - sync()                      : Synchronisiert Absenderdaten live in die DIN-Rücksendezeile.

10. DATUM (47-date-format.js)
   - formatLetterDate()          : Formatiert aktuelles Datum nach DIN 5008 (TT.MM.JJJJ oder YYYY-MM-DD).
   - applyLetterDate()           : Schreibt Datum in das Datumsfeld des Briefes.

11. TEXT FIT ENGINE (48-text-fit.js)
   - constructor(options)        : Initialisiert TextFitEngine.
   - init()                      : Bindet CSS text-fit: shrink & Überlaufschutz ein.
   - scanDOM()                   : Scanned Empfänger-/Info-Blöcke nach Textüberlauf.
   - isOverflowing(el)           : Prüft scrollWidth > clientWidth oder scrollHeight > clientHeight.
   - notifyToast()               : Warnung per Toast bei Textüberlauf.
   - restoreCaretToEnd(el)       : Stellt Cursorposition nach Rollback wieder her.
   - initMutationObserver()      : Überwacht Live-Änderungen an Textfeldern.

12. CONSTANTS & METADATA (51-constants.js, 52-storage.js, 53-metadata.js)
   - saveDraft / loadDraft       : Storage-Layer für Entwürfe.
   - saveSettings / loadSettings : Storage-Layer für Einstellungen.
   - saveCustomFont / load       : Speichern von Benutzer-Fonts.
   - saveGeoapifyKey / load      : Speichern des API-Schlüssels.
   - prepare() / restore()       : Metadaten-Vorbereitung und Head-Injection für Druck/Export.

13. APPLIKATIONSTART & BOOTSTRAP (main.js)
   - syncPostvermerkFromSidebar  : Synchronisiert Postvermerk-Auswahl (z.B. Einschreiben).
   - initApp()                   : Haupt-Bootstrap-Funktion (initialisiert alle Manager).
   - attachGlobalListeners(...)  : Registriert globale Tastenkürzel (Ctrl+S, Ctrl+Z, etc.).
