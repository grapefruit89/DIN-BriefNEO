# old-project-snapshots/

This subfolder contains complete historical snapshots of previous versions of the DIN-BriefNEO project and closely related work.

## Contents
- Full old codebases, including CSS, JS, issues, old specs, and agent-related folders from earlier development phases (primarily 2026-04 timeframe).

## Why archived here
These represent earlier states before:
- Adoption of the strict longevity covenant and W3C-first approach
- Introduction of the current layered antipattern system and Reconciliation/Fitness Score
- Refactoring into the clean ktueller_arbeitsordner/ structure with proper .specify/ and specs/ organization

They are kept for historical reference and to understand the evolution of decisions (useful in a Testballon project).

## What might still be useful
- Old implementations of features (e.g. address handling, salutation, layout) for comparison or to see what was tried and abandoned.
- Historical issues and specs that document why certain paths were chosen.
- Reference for "what did the project look like before X improvement?"

**Do not use code from here directly in current development.** Extract lessons, not copy-paste.

See individual folder README.md files for specifics on each snapshot.
