# external-references/

This subfolder contains forks and external projects that were used as references, inspiration, or comparison material during the development of DIN-Brief Neo.

## Contents
- Various external DIN 5008 CSS implementations, generators, LaTeX letter templates, and simple web letter UIs.

## Why archived here
These were early external inputs. The current project has evolved far beyond them with a custom, highly refined vanilla web implementation focused on longevity, accessibility, and the specific DIN 5008 visual requirements.

Keeping them allows future agents to understand the landscape of existing solutions that were considered.

## What might still be useful
- Alternative approaches to certain DIN 5008 layout or styling problems.
- Historical context for what "off the shelf" solutions looked like.
- Comparison material when evaluating new ideas against past external work.

**These are not to be used as the basis for current code.** They serve as reference only.

See individual folder README.md for details on each reference.
