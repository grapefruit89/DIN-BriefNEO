# deprecated-agent-artifacts/

This subfolder contains obsolete files and folders from previous AI/Agent sessions and temporary development environments.

## Contents (examples)
- .git folders from old temporary clones of projects
- .brain/, .gemini/, .specify/ folders from earlier agent interaction sessions
- Old configuration files, templates, or session outputs (e.g. claude_config_template.json, various changelog/info files)

## Why archived here
These were bloating the repository and the rchiv/ folder, making it hard for new agents to navigate the actual historical project material. They are no longer relevant to current or future development.

They were cleaned up during the June 2026 archive restructuring to reduce noise and improve focus on the active work in ktueller_arbeitsordner/.

## What might still be useful
- Very limited. Mostly for understanding past agent interaction patterns or debugging old session issues if ever needed (rare).
- Some old config ideas might be of minor historical interest.

In general: **Ignore this folder for active work.** It exists purely to preserve (but isolate) old junk.

See the root rchiv/README.md for overall context.
